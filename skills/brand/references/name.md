# Name

Read by `references/adjustments.md`, only when a name is needed: no name
yet, a working name, or a rebrand.

- The name comes last: it carries the purpose, the strategy and the voice
  already settled. Earlier names are working names.
- The **copywriter** proposes three options and one hybrid, each justified
  by `FOUNDATIONS.md` and `STRATEGY.md`, in the voice of `VOICE.md`. Show
  them with your recommendation.
- Send the **analyst** on a quick **name availability** mission for the
  options the user keeps: domain names, social handles, trademark
  databases. The result is an availability check, not legal advice: say so.
- Keep a plan B and a plan C.
- Write the chosen name in `FOUNDATIONS.md`. Write the search (the options,
  the checks, why the others were set aside) in
  `docs/brace/brand/DECISIONS.md`.

For a personal brand, see the name choices in `references/personal.md`.
