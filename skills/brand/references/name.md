# Name

Read by `SKILL.md` before and at the naming meeting (`naming`), only when
a name is needed: no name yet, a working name, or a rebrand that changes
it. A 1.1 mission follows `references/legacy-1.1/name.md`.

The name comes after the strategy and before the look: a logo is drawn
around a name, never the reverse. Earlier names are working names.

## Before the meeting (backstage)

1. **`strategist`**: a one-page naming brief, from the validated platform
   (what the name must carry, what it must avoid, the markets and the
   brand's languages).
2. **`copywriter`**: names generated widely (hundreds is normal), kept in
   its folder.
3. **`analyst`**: the **screening, before anything is shown**: identical
   trademarks (the INPI and TMview free searches), domain names, social
   handles, an unfortunate meaning in the brand's languages, a famous
   homonym that would bury it in searches. A name that fails never reaches
   the client.
4. **`copywriter`** keeps six to twelve names that passed, each with its
   reason; **`brand`** builds the names deck; **`creative-director`**
   reviews.

## The names deck

1. `cover`: the client's criteria for the name (from the naming brief).
2. One slide for the platform, in short.
3. One slide per name: the name in sentences, the way people will meet it
   ("I use X for my timesheets"), **in plain type, never with a logo**, so
   it is judged for itself; its reason; its availability in one line
   (domain, handles, no identical trademark found).
4. `reco`: our recommendation and why, with a plan B.

## The meeting and after

The five parts of `SKILL.md` (a meeting). The client picks a name (or
asks for a new series: `references/adjustments.md`, a new proposal). The
minutes record it; write it in `FOUNDATIONS.md` and the search (the
names shown, the checks, why the others were set aside) in
`docs/brace/brand/DECISIONS.md`. The screening's detail is a read
document in the space (`names-check`).

## The law, said honestly

The screening is never a legal opinion. Say what is right for the
project, only when it matters:

- **Always**: the availability above, so the client does not end up with
  a name already taken or badly received.
- **A new name used commercially** (a company, a product, an app that is
  sold): say that protecting it means filing it as a trademark (at the
  INPI in France, about 190 euros for one class, 40 per extra class), and
  that before filing there are three levels of checking: the free
  identical search on the INPI and TMview databases (done); the INPI's
  similarity search (roughly 50 to 80 euros, to check on inpi.fr); a
  trademark attorney (fees). Recommend the level the project calls for,
  never the most expensive by default. The client decides whether we start
  the creative work before the full check (their risk) or after.
- **A personal brand under the person's own name**: no filing, never
  mentioned.

For a personal brand, see the name choices in `references/personal.md`.
