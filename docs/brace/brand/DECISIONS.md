# BRAND DECISIONS — BRACE

Brand choices: what was tried, why it was set aside, what was kept.

## 2026-10-22 — Tagline, one-liner and test

- **Tagline kept**: "Finally on the same page." Set aside: "Your AI,
  finally on the same page." (longer, the one-liner already says "your
  AI"), "Pick up where you left off." (calm but less memorable), "Never
  explain your project twice." (a "never" promise to prove first).
- **One-liner kept**: "BRACE turns your AI into a real assistant for your
  projects: it remembers, keeps them clean and professional, and follows
  them all." Set aside: memory-only versions ("an organised memory of each
  project"), because BRACE is the whole system, not one more memory tool;
  naming the skills in it, because it would age with each new skill.
  "Your AI" over "your AI agent": simpler, with the platforms always shown
  next to it so no web-app user is misled.
- **Acronym as signature only**: "Barely Remarkable, Admittedly Capable
  Engine", where the name is explained.
- **Test**: a five-second test page (tagline and one-liner, then the
  positioning statement), shared with the questionnaire respondents who
  agreed to be contacted again. Not tested yet: the owner chose to run
  it later.

## 2026-11-07 — Rebranding : l'ampleur, le territoire, l'équipe

- **Ampleur** : un repositionnement. Gardés : le nom BRACE, « Finally on
  the same page. », la personnalité. Écartés : un simple rafraîchissement
  (la promesse resterait sur la mémoire) et un nouveau nom (rien ne le
  justifie).
- **Territoire retenu** : le 3, « Rien sans toi » : BRACE lit, demande au
  lieu de deviner, écrit ce que tu décides, tu tranches. « Des projets qui
  te ressemblent » (la phrase du client) en est la couleur, pas la
  promesse.
- **Territoires écartés** : le 1, « Tout en ordre » (proche d'un outil de
  gestion de projet, reste le premier geste visible) ; le 2, « L'atelier »
  (« agence » laisse croire à des humains) ; le 4, « Qui te ressemblent »
  (promet plus que ce qui existe, « true to you » perd la ressemblance en
  anglais).
- **Phrase en français** : « Enfin sur la même longueur d'onde. » Écartée :
  « Enfin sur la même page. », calque absent des dictionnaires.
- **Équipe** : Julie, Ravi, Constance, Ben, Lou, choisis sur trois tours
  de candidats vérifiés. Écartés à la vérification : Theo, Robin, Simon,
  Alma, Diana, Felix, Victor (Viktor), Hector.
