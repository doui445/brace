# BRAND DECISIONS — BRACE

Brand choices: what was tried, why it was set aside, what was kept.

## 2026-10-22 — Tagline, one-liner and test

- **Tagline kept**: "Finally on the same page." Set aside: "Your AI,
  finally on the same page." (longer, the one-liner already says "your
  AI"), "Pick up where you left off." (calm but less memorable), "Never
  explain your project twice." (a "never" promise to prove first).
- **One-liner kept**: "BRACE turns your AI into a real assistant for your
  projects: it remembers, keeps them clean and professional, and follows
  them all." Set aside: memory-only versions ("an organised memory of each
  project"), because BRACE is the whole system, not one more memory tool;
  naming the skills in it, because it would age with each new skill.
  "Your AI" over "your AI agent": simpler, with the platforms always shown
  next to it so no web-app user is misled.
- **Acronym as signature only**: "Barely Remarkable, Admittedly Capable
  Engine", where the name is explained.
- **Test**: a five-second test page (tagline and one-liner, then the
  positioning statement), shared with the questionnaire respondents who
  agreed to be contacted again. Not tested yet: the owner chose to run
  it later.

## 2026-11-07 — Rebranding : l'ampleur, le territoire, l'équipe

- **Ampleur** : un repositionnement. Gardés : le nom BRACE, « Finally on
  the same page. », la personnalité. Écartés : un simple rafraîchissement
  (la promesse resterait sur la mémoire) et un nouveau nom (rien ne le
  justifie).
- **Territoire retenu** : le 3, « Rien sans toi » : BRACE lit, demande au
  lieu de deviner, écrit ce que tu décides, tu tranches. « Des projets qui
  te ressemblent » (la phrase du client) en est la couleur, pas la
  promesse.
- **Territoires écartés** : le 1, « Tout en ordre » (proche d'un outil de
  gestion de projet, reste le premier geste visible) ; le 2, « L'atelier »
  (« agence » laisse croire à des humains) ; le 4, « Qui te ressemblent »
  (promet plus que ce qui existe, « true to you » perd la ressemblance en
  anglais).
- **Phrase en français** : « Enfin sur la même longueur d'onde. » Écartée :
  « Enfin sur la même page. », calque absent des dictionnaires.
- **Équipe** : Julie, Ravi, Constance, Ben, Lou, choisis sur trois tours
  de candidats vérifiés. Écartés à la vérification : Theo, Robin, Simon,
  Alma, Diana, Felix, Victor (Viktor), Hector.

## 2026-11-07 — Rendez-vous 3 : la plateforme de marque

- **Plateforme validée** : [la plateforme de marque](documents/2026-11-07-platform.html),
  reportée dans les fondations et la stratégie.
- **Ligne d'appui** : « It asks. It writes it down. You decide. » (« Il
  demande. Il écrit. Tu décides. »). Elle prouve la phrase, ne la remplace
  pas.
- **La couleur « des projets qui te ressemblent »** : après la promesse,
  jamais avant ; ce qui ressemble, c'est ce que tu as écrit et validé ; en
  anglais « true to you », « looks like you » écarté.
- **Valeur 3 renommée** : « Vérifier avant d'affirmer », anciennement
  « Honnêteté totale ». Écartés : garder le nom (le mot fait slogan),
  « Rien sans preuve » (se confond avec « Rien sans toi »).
- **Limite de la vie privée** : « BRACE n'envoie rien lui-même. Ce que ton
  agent lit part chez le fournisseur du modèle, comme pour tout agent. Ce
  qui va sur GitHub ou dans tes Rappels, c'est toi qui le décides. »
  Vérifiée dans le code. Écarté : ne rien dire pour l'instant.

## 2026-11-08 — Rendez-vous 4 : la livraison

- **Test** : les personas vérifiés, pas de vraies personnes. *Hypothèse,
  non testée* ([les personas vérifiés](documents/2026-11-08-personas-check.html)).
  Le pilote accepte un plugin de plus s'il peut tout relire : tient, comme
  condition seulement. L'entrepreneur utilise une IA sur sa machine : non
  soutenu (4 répondants sur 6 sont sur une application web). « D'accord »,
  première lecture de « Finally on the same page. » : fragile. « Des projets
  qui te ressemblent » perçu comme un désir : fragile. Écartés : le vrai
  test (pas maintenant, la page reste prête, avec en plus la question de la
  langue maternelle), « pas encore testé ».
- **Phrase et description** validées en place et posées sur la page
  d'accueil et dans les descriptions à l'installation.
- **Transition et annonce** validées. L'annonce part à la sortie de la 1.1.
- **Le dossier** passe de project-tracker à brace (écarté : attendre, la
  recommandation de l'agence).
- **« Formerly project-tracker. »** reste jusqu'à la revue de six mois.
- **Les documents de la mission** gardent les prénoms d'alors ; l'équipe
  devient Julie, Ravi, Constance, Ben et Lou.
- **L'héritage** ([la marque d'avant](archive/2026-11-06/)). Gardés : le
  nom BRACE, la phrase anglaise « Finally on the same page. », le caractère
  (Jarvis), la valeur « ne jamais deviner », le portfolio comme premier
  geste. Abandonnés : la promesse de mémoire (« it remembers », « real
  assistant »), « clean and professional », Claude Code et Antigravity au
  même rang, le design annoncé avant d'exister.
