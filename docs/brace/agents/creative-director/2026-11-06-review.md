## Send-backs

1. **Copywriter, route 3 (README FR and EN, launch post FR and EN) and strategist, routes.md (T3 mechanism): the line on GitHub is inaccurate.**
   "It does not commit or push anything to GitHub without your confirmation" [F2] is false once the user has said yes to `auto_publish` (skills/brand/SKILL.md, "Saving": after the first yes, BRACE commits and pushes what the user validated without asking each time). The README line it is taken from ("Never commits or pushes without confirmation", README line 87) concerns one specific action, on request, and does not cover the brand skill. This is the one claim in the recommended route that a user can catch out, in a route whose whole promise is "I only say what I have checked". It also uses "commit", "push", "GitHub" for an audience that is not only developers (VOICE: unexplained jargon).
   Exact fix: replace by a true, plain sentence, for example "It saves and publishes only what you have approved, and it asks before doing it on its own." (EN) / "Il n'enregistre et ne publie que ce que tu as validé, et il demande avant de le faire seul." (FR). Remove "(README)" as a source in routes.md and cite the preference and its first-time question instead. Re-check the same line in the long install description if it is added there. The deck mockups (14) already leave it out, keep them that way until the copy is corrected.

2. **Brand, slides 6, 10, 14 (mockups): the plugin and the agent disappear.**
   The creative brief says every one-liner and README must show that BRACE needs an AI agent on the machine, so that a web-app user is not misled. Slide 6 (README and post) and slide 14 (post) never say plugin, agent, Claude Code or Antigravity. Only slide 10 says "a free plugin for your AI agent". The copywriter's texts do carry the line. Exact fix: put back in each mockup, from `2026-11-06-words.md`, the sentence "It is a free, open-source plugin for Claude Code and Antigravity, so it needs an AI agent on your computer" (README) and "a plugin for your AI agent" in the posts. Use the copywriter's words as written, not a shortened rewrite.

3. **Copywriter, install descriptions and posts: Claude Code and Antigravity side by side again.**
   Slide 2 and the audit list "Antigravity presented as equal to Claude Code" as something that has aged. The new words repeat "for Claude Code and Antigravity" and "in Claude Code or Antigravity" everywhere. Citing Antigravity is correct, but the brief says it is a fact to state, not a headline. Exact fix: put Claude Code first and Antigravity as the second clause, for example "A free plugin for Claude Code. It also works with Antigravity." Keep it in the descriptions and README, drop it from the post.

4. **Strategist, routes.md "La carte": the free quadrant is not empty.**
   The text says the top-right cell "est vide" and "Libre", but the table puts Tailor Brands and Tab in it. Exact fix: "presque vide" and say in one line why those two do not occupy it (as the table already half does for Tailor Brands), instead of "vide".

5. **Strategist, routes.md (T3 risks) and personas: "il ne devine pas" against the pilot.**
   The pilot, first audience of T3, "veut des agents qui devinent ce qu'il faut avant que tout soit dit" (personas, questionnaire), and FOUNDATIONS defines BRACE as far-sighted, like Jarvis. T3 promises "elle ne devine pas". This is the real tension of the recommended route and it is not in the risk list. Exact fix: add it as a fifth risk in T3 with the resolution (BRACE anticipates what it can read in the files, asks only about what it cannot know), and make sure the T3 headline words follow the same line.

6. **Strategist, routes.md "Pourquoi" (point 1): attributed quote.**
   "Tu l'as dit toi-même à l'atelier, le suivi c'est la même page du projet, la marque et le design c'est 'rien sans toi'." The validated brief says only that the phrase "relie toutes les compétences". "Rien sans toi" is not in the brief and appears only in our own documents. Exact fix: either quote the workshop notes where it was said, or reword to "nous lisons" without attributing the idea to the client. The same sentence must not appear in the deck as the client's.

7. **Brand, slides 4, 8, 12: tagline and support line run together.**
   "Finally on the same page. All your projects, on one page." reads as one long sentence in the green box. Exact fix: put the tagline and its support line on two separate lines (two paragraphs or a line break), as in the copywriter's "Ligne d'appui". Same on slides 8 and 12.

Brand, remove "service premium" and use the analyst's sentence.

10. **Brand, slide 3 (the scope slide) is broken.**
    The list items split into three narrow columns ("Rafraîchir", then ": on garde le coeur" wrapped one word per line), the right column runs below the footer, and the lede's last line is crossed by the footer rule. Re-shoot this slide and check that nothing passes the footer.

11. **Brand, slides 1, 8, 11, 12: French typography.**

Same for "tout / suite" where short words end a line.

- Signal quote: the original dash was replaced by a comma to follow the no-long-dash rule. Fine in a deck, but the source line could say "ponctuation adaptée".
- Cards on slides 7, 11, 15 fill only two thirds of the width and leave the right third empty. Taste.
- "En une ligne : BRACE keeps ..." mixes French and English in one line on slides 4, 8, 12. Acceptable as a label, but a colon and a line break would read cleaner.
- Analyst's benchmark and the references are properly sourced and flag what was not verified (Canva, Servo, Superhuman page, the October rows). No invented figure found. The audit and benchmark are readable for someone outside the trade.
- Personas: the entrepreneur persona is the thinnest, and the document says so itself. Fine for a provisional version.
- Pass on the creative brief: complete, and its own rule on F2 ("Il ne commit ni ne pousse rien sans confirmation (README)") is where the inaccuracy started. It should be corrected at the source (strategist) with send-back 1.
