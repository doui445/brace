# Brief permanent de la stratège (Chloé) : BRACE

Créé le 2026-11-06, à la première mission (rebranding, rendez-vous 2).

## Le projet

BRACE est un plugin libre et gratuit qui transforme une IA sur ta machine en
assistant pour tes projets. Ce dépôt est le plugin lui-même et se suit
lui-même (`docs/brace/`). Mission en cours : un rebranding en cinq
rendez-vous, mené par l'agence BRACE (Alice, directrice de clientèle ;
Bruno, analyste ; Chloé, stratège ; David, rédacteur ; Emma, directrice de
création). Prénoms provisoires : à remplacer par de vrais prénoms.

## À garder en tête

- Langue de travail : le français (documents client, tutoiement). Langue de
  la marque : l'anglais d'abord, le français en second.
- Décidé à l'atelier du 2026-11-06, ne pas rouvrir : le nom BRACE, sa
  signature « Barely Remarkable, Admittedly Capable Engine », la
  personnalité façon Jarvis, les valeurs, la phrase « Finally on the same
  page. » (l'audit vérifie seulement qu'elle tient pour tout le système).
- Public élargi : toute personne qui a plusieurs projets concrets à mener,
  entrepreneurs compris. Version stable pour Claude Code d'abord ;
  Antigravity a surtout testé l'ouverture ; les autres agents sont une
  direction, jamais une promesse affichée.
- Goûts : Jarvis (comportement), Apple (sensation). Jamais : surenchère de
  chiffres, magie promise, mécaniques d'addiction, dark patterns,
  télémétrie, outils imposés.
- Pas d'entretiens réels à ce jour : ne jamais inventer de réponses. Les
  personas sont provisoires.
- Aucun nom de personne privée dans le dépôt. Pas de tiret long.
- Le sous-ensemble Markdown du rendu : titres, paragraphes, listes,
  tableaux, citations, liens, gras, italique, code en ligne. Pas de bloc de
  code, pas de schéma ASCII.

## Corrections du client

- 2026-11-06, rendez-vous 2 : repositionnement choisi (nom, phrase
  « Finally on the same page. », Jarvis gardés). Phrase française : « Enfin
  sur la même longueur d'onde. ». Aucun des trois territoires n'a convaincu
  seul ; le client veut un territoire 4 sur « tes projets à jour, mais surtout
  tes projets qui te ressemblent » (voir `2026-11-06-route-4.md`). Règle :
  aucune promesse publique sur les compétences à venir ni sur la vie privée ;
  « rien n'est jamais oublié » est un argument, pas une promesse écrite.
