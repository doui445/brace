foot: Sous le nom

::: logo
meta: Sous le nom | Pointe vers le bas
title: Sous le nom, | *pointe vers le bas.*
svg: ../designer/files/retouches/sous-le-nom/logo-tip-down.svg
why: Les bouts remontent vers les lettres : le mot est tenu, posé comme sur un socle. C'est le sens le plus proche de « rassembler ». Notre réserve : la forme ouverte peut se lire comme un simple soulignement, ou un sourire.
foot: Sous le nom

::: logo

title: Encadré, | *le nom tenu des deux côtés.*

title: Le A, | *l'accolade dans le nom.*

::: logo
meta: D'autres idées | Le mot entre accolades
title: Entre accolades, | *le mot lui-même.*
svg: ../designer/files/retouches/idees/3-typographique-logo.svg
why: « Brace » est le mot anglais pour accolade : le nom devient le signe. Il s'écrit partout, même dans un terminal. Ce que ça coûte : c'est la forme la plus attendue. Nous la voyons comme une version de secours, pas comme le logo.

::: palette
meta: Le système | Les couleurs
title: Ta palette tient, | trois réglages.
intro: Elle est cohérente : une famille chaude, et un seul froid, le pétrole, rare et visible. Premier réglage, un seul noir pour l'encre et le fond sombre, au lieu de deux presque identiques. Deuxième, une surface un peu plus claire pour les blocs posés sur le fond sombre. Troisième, une règle : aucun texte plus clair que le gris sur ton papier. Sur ton papier, l'encre se lit à 16:1, le gris à 6:1, le pétrole à 6,5:1. Les chiffres sous chaque couleur sont mesurés sur blanc et sur noir.
swatch: #F4F1EA | Papier | neutral
swatch: #171614 | Encre et fond sombre | main
swatch: #5F5B53 | Gris | neutral
swatch: #1D5E66 | Pétrole | accent
swatch: #6FB7BE | Pétrole clair, pour le sombre | accent
swatch: #211F1C | Surface sombre, nouvelle | neutral
foot: Le système
