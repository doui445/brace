## Limites et points à voir
1. **Chemin du thème** : `theme: ../../../../../brand/brand.css`, calculé pour un Markdown dans `docs/brace/brand/documents/06-delivery/` et `brand.css` dans `brand/` à la racine du projet (cinq niveaux). `render.py` résout le thème depuis l'emplacement du Markdown : rendu depuis `agents/designer/`, il échouerait (« no such theme »). Si `brand.css` finit dans `docs/brace/brand/`, remplacer par `../../brand.css`. Les liens internes supposent : plateforme `../2026-11-07-platform.html`, guide éditorial `../05-refinement/2026-11-19-editorial-guide.html` (la version actuelle, à mettre à jour si un nouveau guide est rendu en 06-delivery), et les deux documents entre eux par nom.
2. **Images dans les documents** : le Markdown ne peut pas montrer les logos ni les nuanciers. La planche rendue en HTML est donc textuelle ; l'image complète est `brand-board.png`. Proposition (hors de mon périmètre) : une ligne `![alt](fichier)` dans `render.py`, ou publier le PNG à côté de la planche.
3. **Les trois adjectifs** : calme, fiable, franc, pris dans la liste du caractère de FOUNDATIONS (autonome, fiable, attentif, prévoyant, calme, franc). La marque n'a pas de liste de trois fixée : à faire confirmer par le client. Alternative tirée de VOICE : calme, clair, franc. Dans le PNG ils sont en anglais (Calm, Reliable, Frank), dans le Markdown en français.
4. **Fond du README** : les panneaux GitHub clair (`#FFFFFF`) et sombre (`#0D1117`) sont ceux de GitHub, pas de la marque ; ils servent à montrer que le logo tient sur ces deux fonds. Les pages dessinées sont des maquettes simplifiées (aucune capture de GitHub, aucune image tierce) ; les autres plugins de la liste sont des gris neutres sans nom. La phrase « Finally on the same page. » est celle gardée aux décisions.
5. **Texte du terminal** : les deux répliques viennent de la voix de BRACE (exemples de VOICE.md), « Done. 3 files updated. » est ajoutée ; à relire par la copywriter.
6. **Règles que j'ai fixées** (à valider) : espace de protection = hauteur du B du nom ; tailles minimales 96 px / 25 mm pour le logo, 16 px pour le B, 24 px pour le symbole ; aucune valeur CMJN/Pantone (BRACE n'est pas imprimé).
7. **Qui demander, qui tient à jour** : pendant la mission Julie ou Isabelle ; ensuite le client. Formulation de proposition, à confirmer avec Julie.
8. Les icônes PNG de 16 à 48 px sont rendues par le navigateur à la taille réelle (pas réduites d'une grande image).
9. Messages du générateur : « ltag NOT subset » est sans effet (table de langue de la police).
