# BRIEF: analyst

- **Project:** BRACE, a plugin giving AI coding agents on the user's machine (Claude Code, Antigravity) a project memory. The memory is tracking files, a portfolio page, Reminders and calendar follow-up, and skills such as brand.
- **Owner's positioning:** no real direct competitor; the alternative is combining several tools yourself.
- **Competitor levels:** (1) chat apps, SaaS and IDE extensions; (2) skill packs, "ecc" being Everything Claude Code; (3) outside-terminal assistants. Plus native memory.
- **Watch:** native memory shipped by Anthropic, OpenAI and Google; star and version changes for superpowers, ECC, claude-mem, BMAD and Spec Kit; new "assistant with memory" launches.

## Owner's corrections (2026-10-19)

- BRACE is not just memory: it is organised, relevant memory. Compare it on
  that, not on "remembers" alone.
- The tools BRACE proposes (superpowers included) are never mandatory and
  are proposed only when justified. BRACE is meant to stay light and save
  tokens, so the user no longer has to worry about cost either.
