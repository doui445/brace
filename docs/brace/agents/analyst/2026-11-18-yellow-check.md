# Contrôle du jaune et du monogramme B : BRACE (2026-11-18)
Asked by: brand (Julie). Depth: quick.

Pages rendues vues dans un navigateur le 18 novembre 2026 (captures), couleurs lues dans le code de la page quand c'est indiqué. Un contrôle rapide, pas un avis juridique : « rien trouvé » veut dire rien trouvé en une passe rapide.

## Summary
- Le jaune n'est pas tenu par les voisins directs de BRACE (superpowers, ECC, claude-mem, Spec Kit, BMAD, Taskmaster, Claude Code, Antigravity).
- Mais le jaune sur noir est tenu dans l'IA de code : Kilo (kilo.ai) a un fond #0A0A0A, un jaune #FFDD00 en bandeau et boutons, et un logo en lettres blanches dans un carré. La phrase « personne ne tient le jaune » est donc fausse telle quelle.
- Le jaune est aussi la couleur de Brandmark et l'exemple phare de Looka (outils de logo), mais pas leur logo.
- Aucun monogramme B jaune sur tuile sombre trouvé. Deux B proches : BrandingStudio.ai (B en dégradé bleu-violet, sur fond sombre) et BMAD (tuile « BM/ad » bleue).
- Différence défendable pour BRACE : jaune sourd en surligneur sous un mot-symbole serif, contre jaune vif plein en aplat chez Kilo.

## Added beyond the brief
Kilo, Bun, Biome, Bolt et Blackbox AI : ils ne figuraient pas dans la liste, mais Kilo est précisément le cas qui contredit la phrase du deck. Beads (dépôt GitHub) a été ouvert, sans logo lisible dans la capture : non vérifié.

## Open spaces
- Un surligneur jaune sourd sous un mot écrit en serif : personne trouvé. Kilo tient un jaune vif en aplat et en pixels, monospace.
- Un B clair sur tuile sombre avec un trait jaune sous sa moitié basse : introuvable en une passe rapide. Le B le plus proche est celui de BrandingStudio.ai, violet.

## Unverified
- superpowers : aucun logo ni couleur lisibles dans le README ni la capture ; le logo « Prime Radiant » n'a pas été vu.
- Spec Kit : la page GitHub n'a montré aucun logo ni couleur de marque lisible dans la capture.
- Le logo exact de Kilo (lettres en pixels) est vu en capture agrandie, mais la signification de la forme n'est pas confirmée.
- Les registres de marques n'ont pas été interrogés : un contrôle d'antériorité d'un B jaune sur tuile sombre reste à faire, et il ne vaut pas avis juridique.
- Les autres monogrammes B de petits outils ou de plugins Claude Code n'ont pas pu être balayés exhaustivement : la recherche web n'en a remonté aucun, mais elle ne couvre pas les registres de plugins.
