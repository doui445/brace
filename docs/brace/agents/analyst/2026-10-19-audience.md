# Audience: BRACE (2026-10-19)
Asked by: the brand skill (first brand session). Depth: full.

Method: quotes come from the Hacker News Algolia API (link pattern `https://news.ycombinator.com/item?id=<id>`) and one DEV post. Several authors are people launching their own memory tool, marked "builder". Their pain statements are real but double as pitches.

## Summary
- The clearest pain is among coding-agent users: sessions start blank, decisions get re-invented, the project gets re-explained.
- Stale notes come second. Hand-kept CLAUDE.md and memory files drift out of date, which supports "kept current" over "written once".
- Running several projects or sessions is a recognised mental load.
- Chat-app users are split: some call memory the best feature, others report leaks between projects.
- superpowers is loved by some and dropped by others for token cost and overkill.
- I found no voice from non-developers on "hassle", and that gap is itself a finding.
