# Les prénoms du directeur artistique et du designer (2026-11-18)

Contrôle de disponibilité, pas un avis juridique. Profondeur : rapide (quelques recherches web par prénom, lectures faites le 2026-11-18). Rapport interne : seuls les prénoms qui passent vont au client.

## Résumé

- **Directeur artistique** : Olivier passe (clair). Margot, Isabelle et Nicolas passent avec un doute mineur. Vincent passe de justesse : l'écho avec l'auteur de superpowers, que BRACE propose lui-même, est réel.
- **Designer** : Hélène, Daniel et Maxime passent (rien trouvé, recherche large). **Agnès a un doute plus fort que prévu** : Agnes AI vend un agent de code, Agnes Code (juillet 2026). Arthur : Arthur AI est connu dans l'écosystème agents, avec un skill Claude Code.
- Aucun prénom écarté d'office, mais Agnès et Arthur ne sont plus les deux valeurs sûres du document de Ben.
- Limite : une à deux recherches par prénom. « Rien trouvé » veut dire « rien de visible », pas « rien n'existe ».

## Ajouts hors demande

- Le cas Vincent : superpowers fait partie de l'univers que BRACE propose. Un client qui connaît le plugin entendra le nom de son auteur. Pas un blocage, mais à savoir.
- Ollie, assistant d'IA axé confidentialité, a fermé le 2026-10-30. Sans lien avec Olivier, mentionné pour éviter une fausse alerte : [TechCrunch](https://techcrunch.com/2026/10/30/ollie-a-privacy-focused-ai-assistant-is-shutting-down/?rand=23331).

## Ce qui passe, par poste

- **Directeur artistique** : Olivier (clair), puis Nicolas, Isabelle, Margot (doute mineur), Vincent en dernier.
- **Designer** : Hélène, Daniel, Maxime (rien trouvé), puis Arthur. Agnès reste possible mais déconseillée si le client est sensible à l'univers des agents de code : Agnes Code est un agent de code lancé cet été.

## Non vérifié

- Ampleur réelle d'Agnes AI : le site officiel n'a livré que son titre, la couverture lue est en partie sponsorisée.
- Les prénoms « clairs » ont reçu une recherche large, pas un passage par registre (npm, GitHub, places de marché de plugins, Antigravity).
- Aucune vérification de marques ni de noms de domaine : non demandée ici.
