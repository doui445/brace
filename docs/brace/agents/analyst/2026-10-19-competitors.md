# Competitors: BRACE (2026-10-19)
Asked by: the brand skill (first brand session). Depth: full.

## Summary
- The owner's "no direct competitor" holds for the whole bundle (memory, portfolio, Reminders and calendar, brand skill). Each piece still has a loud, free, popular rival: superpowers (about 302k GitHub stars), ECC (about 284k), Spec Kit (about 142k), claude-mem (about 102k).
- "ECC" is Everything Claude Code, by affaan-m. It calls itself "the agent harness performance optimization system", with 71 agents, 311 skills and a memory vault. It is the closest feature-for-feature rival, and its tagline is "Optimize the context window. Persist everything else."
- Nobody I found holds the multi-project view for a non-expert: a portfolio page across all projects plus Reminders and calendar follow-up. The nearest are session dashboards for developers (Agent View, CCDash, Panoptes).
- Native memory now exists almost everywhere: Claude Code auto memory, ChatGPT, the Claude chat app, Meta Muse. "The AI never forgets" is no longer distinctive alone. "Memory you can read, in files in your project" still is.
- Level 3 is crowded and fast-moving (Meta Muse, Tab, OpenClaw, Hermes, Cowork). Those products mostly sell outcomes ("does things"), not project quality.

## Added beyond the brief
- ECC identified as Everything Claude Code (affaan-m), not a generic acronym.
- Other Level 2 packs: claude-mem, GitHub Spec Kit, BMAD-METHOD, Taskmaster.
- Session dashboards (Agent View and community tools), as the substitute for "follow all your projects".
- Level 3 examples the owner lacked: OpenClaw, Hermes, Meta Muse, Tab, Notion AI, Manus, Cowork.
- Native memory in Claude Code and Antigravity, since they are BRACE's own hosts.
- The "do it by hand" substitute: a hand-written CLAUDE.md or AGENTS.md. People describe it going stale (see audience).

## Open spaces
- **Memory you can read and commit.** Plain tracking files in the project, versus a database (claude-mem), opaque cloud memory (ChatGPT, Muse) or notes only (CLAUDE.md). ECC's Markdown vault is the nearest, but it stores memories, not a project record.
- **Project hygiene for non-experts.** I found nobody selling "the project stays clean and organised". superpowers sells process, ECC sells performance, claude-mem sells recall.
- **A portfolio across all projects with real-world follow-up** (Reminders, calendar). Dashboards cover live sessions only.
- **A calm, low-ceremony tone.** The packs are dense and hype-driven (counts of agents and skills). Tab's "Trust is the product" shows a reassuring tone works in Level 3, but nobody holds it among agent plugins.
- **Two hosts, one memory** (Claude Code and Antigravity). ECC supports more harnesses, but I did not verify whether it shares a project memory across them.
- **A short curated toolbox.** I found nobody "proposing the best tools to install". Users complain about bloat (see audience), so curation has to stay short.
