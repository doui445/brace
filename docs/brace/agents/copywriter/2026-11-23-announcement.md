Ce document annonce la nouvelle identité visuelle de BRACE, validée le 23 novembre. Il contient deux textes en anglais, la langue de la marque : une note de version pour GitHub, et un court post. Chacun dit la même chose en trois temps : ce qui est nouveau, pourquoi l'accolade, et ce qui ne change pas.

Les textes sont prêts. Tu les publies le jour de la sortie de la prochaine version, comme le prévoit le plan de transition, pour que ce que l'annonce décrit soit ce que les gens voient : le nouveau logo, les polices et les couleurs sont alors en place dans le dépôt. La note de version se publie sur la page des versions du dépôt. Aucune date n'est écrite dans les textes.

Le court post est facultatif. Nous n'avons trouvé aucun compte sur les réseaux pour BRACE. Il est écrit pour le compte que tu as déjà ou que tu ouvriras, et tu peux ne pas l'utiliser.

Le nom ne change pas, il n'y a donc pas de mention « formerly » : celle du README reste telle quelle. L'annonce ne parle ni de compétences à venir, ni de vie privée, ni d'autres outils. Elle dit qu'il faut un agent IA sur l'ordinateur, comme toute prise de parole publique de BRACE.

## La note de version GitHub

Environ 120 mots.

> **BRACE has a new look.**
>
> A petrol brace now sits above the name, tip up. It holds the word the way BRACE holds your project: together with you, with every tracking file in one place.
>
> The rest follows. Warm paper, one black, a rare touch of petrol. Bricolage Grotesque for text, Commit Mono for commands, and a hand-drawn B as the tab icon.
>
> Nothing changes in how BRACE works. It asks. It writes it down. You decide. Your projects, your files and your commands stay as they are.
>
> A free plugin for Claude Code, it also works with Antigravity. It needs an AI agent on your computer.
