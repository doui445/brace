## Le projet

BRACE, un plugin libre et gratuit pour les agents IA sur la machine
(Claude Code d'abord, fonctionne aussi avec Antigravity). Il garde la
mémoire d'un projet dans des fichiers lisibles, demande ce qu'il ne peut
pas savoir, et met tous les projets sur une seule page. Le projet se suit
lui-même dans `docs/brace/`.

Plateforme validée : `docs/brace/brand/FOUNDATIONS.md` (dont la Boussole,
six questions pour trancher), `STRATEGY.md`, `VOICE.md`. Brief du visage
validé le 2026-11-17 : `docs/brace/brand/BRIEF.md`.

## À garder en tête

- Nom toujours **BRACE**, en capitales. La signature « Barely Remarkable,
  Admittedly Capable Engine » ne fait pas partie du logo.
- Page blanche : aucun visuel existant. Le logo doit tenir en une couleur
  (impression possible plus tard, codes d'impression non fixés).
- Le client aime le calme et le nu (Apple, Things, Linear) : beaucoup
  d'air, peu de couleurs, une typographie soignée. Critère : on lui fait
  confiance au premier coup d'œil.
- Jamais : clichés de l'IA (violet, étincelles, cerveaux, robots, néons,
  orbes), look hacker (vert sur noir, matrice, glitch). Mascotte et style
  SaaS d'entreprise : ouverts sans conviction.
- Couleurs à éviter : terre cuite orangée (hôte, ECC), violet et indigo.
  Bleu possible mais encombré (Linear, Things, Spec Kit, GitHub).
- Montrer un geste, pas un adjectif : ni cadenas, ni bouclier, ni coche.
- L'accolade `{ }` seulement si une piste la rend propre à BRACE.
- Un signe lisible sans le nom (avatar rond, 16 px) et un nom écrit qui
  tient seul dans un terminal. Être sobre ne suffit pas : superpowers
  occupe déjà le silence.
- Supports : README GitHub (fonds clair `#FFFFFF` et sombre `#0D1117`),
  avatar GitHub, liste des plugins, portfolio, espace client, terminal,
  notification macOS.
- Outils : tout en code (SVG, CSS) par le designer. Canva du client pour
  explorer seulement, images générées dans `brand/sources/` uniquement.
  Polices libres à licence claire (OFL, Fontshare, Velvetyne). Ne pas
  reprendre Fraunces et Inter : ce sont les polices du gabarit de
  présentation de l'agence, et Inter est cité comme cliché de l'IA.
- Équipe : Julie (directrice de clientèle, skill brand), Ben (rédacteur),
  Lou (directrice de création, revue), Ravi (analyste).
- Langue de travail : français. Langue principale de la marque : anglais.
